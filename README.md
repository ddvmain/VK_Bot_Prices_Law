# ВКонтакте-бот с каталогом юридических услуг

Интерактивный каталог консультационных и юридических услуг для малого и среднего бизнеса (МСБ). Бот работает в личных сообщениях сообщества ВКонтакте.

## Возможности

- Главное меню с тремя разделами: список услуг, прайс-лист, связь с менеджером
- Каталог из 6 разделов и 34 услуг с ценами
- Прайс-лист с блоком «Условия»
- Карточки услуг с описанием, ценой и примечаниями
- Связь с менеджером (ссылка на диалог + уведомление)
- Антиспам: не более одного уведомления менеджеру в 10 минут

## Настройка сообщества ВК

1. Создайте сообщество ВКонтакте (или используйте существующее).
2. Включите **сообщения сообщества**: Управление → Сообщения → Сообщения сообщества — включить.
3. Включите **возможности ботов**: Управление → Сообщения → Настройки ботов — включить.
4. Добавьте кнопку **«Начать»**: Управление → Сообщения → Настройки ботов → Кнопка «Начать» — включить.
5. Включите **Long Poll API**: Управление → Работа с API → Long Poll API — включить.
6. Создайте ключ доступа: Управление → Работа с API → Ключи доступа — создать ключ с правом **«Сообщения сообщества»**.
7. Скопируйте токен и ID сообщества в `.env`.

## Запуск

### Локально

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd vk-catalog-bot

# 2. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate  # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить окружение
cp .env.example .env
# Отредактируйте .env — заполните VK_GROUP_TOKEN, VK_GROUP_ID и другие переменные

# 5. Запустить бота
python -m bot
```

### Через Docker

```bash
# 1. Настроить окружение
cp .env.example .env
# Отредактируйте .env

# 2. Запустить
docker compose up -d
```

## Редактирование каталога и текстов

### Каталог услуг

Файл `data/catalog.json` содержит все услуги, разделы и цены. Структура записи:

```json
{
  "id": "doc_claim",
  "section": "documents",
  "short_title": "Претензия / ответ на претензию",
  "title": "Подготовка досудебной претензии / ответ на претензию",
  "emoji": "📄",
  "description": "…",
  "price": {"kind": "range", "from": 10000, "to": 25000, "unit": "rub"},
  "price_note": null
}
```

Допустимые значения `price.kind`:
- `range` — вилка «от…до»
- `from` — только «от»
- `free` — бесплатно
- `regional` — две цены (Нижний Новгород / Москва, СПб, иные города)

Допустимые `unit`: `rub`, `rub_per_hour`, `rub_per_month`, `rub_per_session`.

### Тексты

Все пользовательские тексты находятся в `bot/texts.py`. Заказчик может править этот файл без изменения логики.

## Тесты

```bash
pytest
```

Проверяют:
- 6 разделов, 34 услуги, обязательные поля, уникальные id
- Форматирование цен, длина сообщений ≤ 4096
- Ограничения клавиатур ВК (≤ 10 строк, ≤ 5 кнопок, подпись ≤ 40 символов, payload ≤ 255 байт)

## Вопросы к заказчику

Все вопросы закрыты заказчиком (обновлено 02.10.2026):

1. ✅ **Почасовые ставки:** «Прочие консультации» и «Иные услуги» — обе от 8 000 ₽/час.
2. ✅ **Часы сверх пакета:** минимальная ставка 8 000 ₽/час, максимум столько же часов, сколько включено в тариф.
3. ✅ **Раздел 4:** «регуляторные письма» заменены на «внутренние нормативные акты».
4. ✅ **Пакетные предложения:** только для Нижнего Новгорода. Москва и Санкт-Петербург — индивидуальный расчёт.
5. ✅ **Участие онлайн в Москве/СПб:** установлена верхняя граница 50 000 ₽.
6. ✅ **Описания услуг:** в карточках добавлена пометка «Описание услуги находится на согласовании».
7. ✅ **Рабочее время:** 10:00–18:00. **Название компании:** БутиК «Ваш личный Советник».
